Two-dimensional Zak phase is largely the same as the one-dimensional [Zak phase]({{ site.baseurl }}{% link _global_charges/zak_phase.md %}), but it is defined for a two-dimensional system, such as the 2D SSH-model *citation*.



$$\theta_{Z,i} = \int_\mathcal{C} dk_i \mathcal{A}_{n,i}(k)$$



Note that $C_4$ symmetry enforces $\theta_{Z,x} = \theta_{Z,y}$.
